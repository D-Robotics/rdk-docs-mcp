# rdk-docs-mcp

检索 [D-Robotics 资料中心](https://developer.d-robotics.cc/rdk_doc_center/) 与 [社区论坛](https://forum.d-robotics.cc/) 的 MCP Server。

给 Agent 这一句：

```text
根据 https://cdn.jsdelivr.net/npm/rdk-docs-mcp@latest/install.md 安装 RDK 文档检索。
```

或本机直接：

```bash
npx -y rdk-docs-mcp@latest --install
```

需要 Node.js 20+。无需登录、无需 API Key。
